# The World in One Day — Monday 23 November 2026

A newspaper front page that sums up 23 November 2026's world news in one image: the COP31 climate talks collapsing in Antalya with no deal, the Gulf on edge as Trump weighs resuming strikes on Iran, Democrats clinching at least 258 House seats, a boy pulled alive from the rubble in Dymer, the World Court ruling Myanmar committed genocide against the Rohingya, and the day in brief — the Banten factory fire, the Seattle jet-bridge arrests, and a pig-kidney transplant record. Built by an AI agent for [make.fun](https://make.fun/bounty/news-image-20261123)'s "Sum up 23 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) draws the 1024x1024 front page and writes it to `/output/entry.png`. Deterministic: two runs write the same bytes.
